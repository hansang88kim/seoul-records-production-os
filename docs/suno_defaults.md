# Seoul Records · Suno 생성 기본값

사용할 Suno Workspace와 앨범 이름을 확정합니다. Quick Single은 새 곡에 길이 하나를 배정하고, Auto Batch는 제목·스타일·가사와 함께 앨범의 길이 배정을 저장합니다. 기본 보컬은 여성입니다.

| 고급 → 추가 옵션 | 곡별 설정 |
|---|---|
| 보컬 성별 | Female |
| 길이 | Custom에서 배정 길이 입력 |
| 개인화 | 켬 |
| Max 모드 | 켬 |

길이 후보는 **2:50, 2:55, 3:00, 3:05, 3:10, 3:15, 3:20**입니다. 앨범마다 일곱 개를 섞어 한 번씩 사용합니다. 8곡째부터 다시 섞되 앞 묶음의 마지막 값과 다른 길이로 시작합니다. 편집·실패 재시도·다시 열기에는 이미 배정한 값을 유지합니다. 이전 기본값인 3:05는 길이 정보가 없는 단일 초안의 대체값으로 남겨 두었습니다.

## 웹 입력 및 검수

1. [Song Lab]에서 곡별 제목, 스타일, 가사, 길이를 확인합니다. **Suno 웹 설정**의 JSON을 저장할 수 있습니다. ChatGPT 제작실의 곡 요청을 사용하면 승인한 제목·스타일·가사 초안을 해당 요청에 저장하고 Suno에서 생성합니다.
2. 매번 생성 직전에 Suno 웹의 **고급 → 추가 옵션**을 열어 위 네 항목을 확인합니다. 새 생성 화면에서 옵션이 초기화될 수 있습니다.
3. 생성 결과에서 실제 재생시간과 완성도를 확인해 사용할 버전을 고릅니다. 목표 길이는 생성 결과에 따라 달라질 수 있으므로 재생 시간은 곡 목록에서 다시 확인합니다.
4. 선택한 버전의 원본 WAV를 Suno에서 내려받아 가져옵니다. Manual WAV Import는 실제 길이와 PCM WAV 검수 결과를 표시합니다. 배포에는 곡별 원본을 보관합니다.

기존 CLI 경로에서는 보컬을 전달하고 배정 길이를 스타일 지시에 넣습니다. 현재 CLI는 웹의 Custom 길이·개인화·Max 모드 직접 설정을 지원하지 않으므로 해당 설정이 필요한 곡은 웹에서 생성합니다. 옵션 기본값은 [프리셋](../presets/suno/seoul_records_defaults.json)을 사용합니다.
