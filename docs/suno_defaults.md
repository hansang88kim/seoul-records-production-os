# Seoul Records · Suno 생성 기본값

사용할 Suno Workspace와 앨범 이름을 확정합니다. Quick Single은 새 곡에 길이 하나를 배정하고, Auto Batch는 제목·스타일·가사와 함께 앨범의 길이 배정을 저장합니다. 기본 보컬은 여성입니다. 앨범별 곡 수, 언어, 목표 길이와 남녀 보컬 비중은 사용자의 요청을 우선합니다. 여러 시티팝 스타일을 요청한 경우 곡마다 편곡 방향을 배정합니다. 곡 초안의 가사·스타일·제목은 독립된 복사 항목으로 제공합니다.

| 고급 → 추가 옵션 | 곡별 설정 |
|---|---|
| 보컬 성별 | Female |
| 길이 | Custom에서 배정 길이 입력 |
| 개인화 | 켬 |
| Max 모드 | 켬 |

길이 후보는 **2:50, 2:55, 3:00, 3:05, 3:10, 3:15, 3:20**입니다. 앨범마다 일곱 개를 섞어 한 번씩 사용합니다. 8곡째부터 다시 섞되 앞 묶음의 마지막 값과 다른 길이로 시작합니다. 편집·실패 재시도·다시 열기에는 이미 배정한 값을 유지합니다. 이전 기본값인 3:05는 길이 정보가 없는 단일 초안의 대체값으로 남겨 두었습니다.

## 웹 입력 및 검수

1. [Song Lab]에서 곡별 제목, 스타일, 가사, 길이를 확인합니다. **Suno 웹 설정**의 JSON을 저장할 수 있습니다. ChatGPT 제작실의 곡 요청을 사용하면 승인한 제목·스타일·가사 초안을 해당 요청에 저장하고 Suno에서 생성합니다.
2. 매번 생성 직전에 Suno 웹의 **고급 → 추가 옵션**을 열어 위 네 항목을 확인합니다. 새 생성 화면에서 옵션이 초기화될 수 있습니다.
3. 생성 결과에서 실제 재생시간과 완성도를 확인해 사용할 버전을 고릅니다. 목표 길이는 생성 결과에 따라 달라질 수 있으므로 재생 시간은 곡 목록에서 다시 확인합니다.
4. 선택한 버전의 원본 WAV를 Suno에서 내려받아 가져옵니다. Manual WAV Import는 실제 길이와 PCM WAV 검수 결과를 표시합니다. 배포에는 곡별 원본을 보관합니다.

## Suno Studio 내보내기와 보관

1. 요청한 Workspace에서 확정한 버전만 선택합니다. 제목이 같은 결과가 있으면 기록한 버전과 실제 재생시간을 대조합니다.
2. Studio에서 선택 버전을 연 뒤 프로젝트명을 정식 곡 제목으로 바꿉니다. `Export` → `Full Song`을 선택하고 라이브러리에 저장된 새 버전을 확인합니다. 지정한 Workspace에 그 버전을 넣습니다.
3. 저장한 Studio 버전을 WAV로 내려받아 곡 이름의 원문 표기를 유지합니다. 요청한 월별 위치의 Workspace 이름 폴더에 보관합니다. Windows OneDrive를 지정한 경우 경로 형식은 `OneDrive/문서/유투브 음악/YYYYMM/<Workspace>/`입니다.
4. 파일별 WAV 형식·PCM·재생시간·개수와 Workspace 내보내기 결과를 대조합니다. 같은 곡을 재개할 때는 저장된 Studio 버전과 파일을 먼저 확인하고 이미 원본이 있으면 재사용합니다. 곡 삭제는 별도로 요청된 범위에서 처리합니다.
5. 다운로드 차감 확인을 요청받으면 같은 시도의 **곡 다운로드 잔여 횟수**를 전후로 조회합니다. 전후 값이 없으면 확인된 잔여 횟수와 그 시점만 기록합니다.

기존 CLI 경로에서는 보컬을 전달하고 배정 길이를 스타일 지시에 넣습니다. 현재 CLI는 웹의 Custom 길이·개인화·Max 모드 직접 설정을 지원하지 않으므로 해당 설정이 필요한 곡은 웹에서 생성합니다. 옵션 기본값은 [프리셋](../presets/suno/seoul_records_defaults.json)을 사용합니다.
